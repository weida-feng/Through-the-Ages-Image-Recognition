# Public package scope

This package presents aggregate historical results and selected demonstrations. The author's original project date is 2022, with code organization, pandas automation and further verification in 2026.

| Included | Purpose |
| --- | --- |
| 20 reusable Python package files | Show the recognition, quality-control, data-preparation and analytical implementation |
| Two `.py` demonstration scripts | Run sample analysis and selected-crop classification without the private archive |
| Original four PCA/KNN files and metadata | Exercise the historical classifiers with their recorded versions |
| Four selected card/empty-region crops and one template | Show recognition and an interpretable failure case without full screenshots |
| Pseudonymized 20-game analysis sample | Preserve real card/outcome values and demonstrate joins, validation and aggregation |
| Full historical aggregate statistics and figures | Present the 14,557-game study with explicit populations, counts and sensitivity |
| Verification summary and public-file hashes | Record local checks and the provenance of this curated copy |
| Manifest maintenance script | Refresh public-file sizes and hashes and verify them in GitHub Actions |
| Public tests and an analysis workflow | Check units and included examples; full private integration checks stay local |

Original usernames, game identifiers, workbooks, complete screenshots, detailed prepared records, discrepancy exports, identity mappings, old notebooks and the full original environment export remain in the local evidence archive. The public sample replaces identifiers consistently and omits original source paths/rows. This retains sample-local relationships rather than promising that every game could never be identified from external information.

The full aggregate reports contain counts of distinct usernames, not username lists. Prepared record-level outputs belong under the ignored `results/` directory. The public `.gitignore` also excludes the historical input directories and common identity-map filenames, while the prepared package itself contains only the selected files listed in its manifest.

The public analysis example reproduces **sample** metrics; reproducing all full-archive totals and original workbook comparisons requires the private historical inputs. The public image example starts from selected crops; its full screenshot integration evidence comes from the local checks. These scopes are stated separately in the README and verification notes.
