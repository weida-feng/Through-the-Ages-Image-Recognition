# Third-party materials

The game context and card-image examples come from the digital board game **Through the Ages**. The four selected crops and empty-region template are game-derived visual material; they are identified separately from the author's Python implementation and documentation. Original full screenshots are not included in this public package.

The project uses NumPy, pandas, SciPy, scikit-learn, joblib, OpenCV, openpyxl and optional matplotlib. Historical automation also references PyAutoGUI, pyperclip and PyDirectInput. These dependencies retain their respective project licenses and are installed separately rather than bundled as source.
